# Ипотечный калькулятор с дашбордом

Веб-приложение на Python и Streamlit: рассчитывает ипотеку по аннуитетной и
дифференцированной схеме, показывает итоговые показатели, график платежей и
интерактивные графики Plotly, выгружает таблицу в CSV.

## 1. Назначение и возможности

Сервис отвечает на вопрос «сколько будет стоить эта ипотека». Пользователь
задаёт параметры кредита и сразу видит платёж, переплату и полный график
платежей по месяцам.

**Что умеет:**

- **Два типа платежа.** Аннуитетный (одинаковый платёж весь срок) и
  дифференцированный (платёж убывает, проценты начисляются на остаток).
- **Итоговые показатели.** Ежемесячный или первый платёж, сумма кредита и доля
  первоначального взноса, переплата по процентам и её доля от кредита, общая
  сумма выплат.
- **График платежей.** Полная таблица по месяцам: дата, платёж, проценты,
  основной долг, остаток. Плюс сводка по годам.
- **Четыре интерактивных графика.** Остаток долга с накопленной выплатой тела
  кредита, структура каждого платежа, доля переплаты в общей сумме, сравнение
  двух типов платежа.
- **Экспорт в CSV.** Файл открывается в Excel без настройки кодировки:
  разделитель `;`, десятичная запятая, BOM UTF-8.
- **Светлая и тёмная темы.** Переключаются в сайдбаре, применяются к интерфейсу
  и ко всем графикам.
- **Проверка ввода.** Отрицательные, нулевые, пустые и нечисловые значения,
  взнос больше стоимости, ставка вне 0–100 %, срок вне 1–600 месяцев. Ошибки
  показываются списком, расчёт останавливается без падения приложения.
- **Автоматические тесты.** 36 тестов на формулы, границы, валидацию,
  форматирование, CSV и построение графиков.

**Чего сервис не делает:** не хранит данные, не требует регистрации, не
обращается к внешним API. Все расчёты выполняются локально в браузере
пользователя.

### Боковая панель

Сверху вниз:

- **Стоимость недвижимости, ₽** — полная цена объекта.
- **Первоначальный взнос, ₽** — сумма, которую вы платите сразу. Под полем
  показывается доля взноса и сумма кредита.
- **Годовая ставка, %** — ползунок от 0 до 100 с шагом 0,1.
- **Срок, лет** — ползунок от 1 до 50.
- **Тип платежа** — переключатель «Аннуитетный / Дифференцированный».
- **Дата первого платежа** — от неё строятся даты в таблице.
- **Сбросить параметры** — возвращает значения по умолчанию, не перезагружая
  страницу.
- **Тема** — «Светлая / Тёмная».

### Основная область

- **Четыре карточки показателей.** Для дифференцированного платежа первая
  карточка называется «Первый платёж», для аннуитета — «Ежемесячный платёж».
- **Строка-пояснение.** Фиксированный платёж или диапазон «с … до …», первая и
  последняя даты платежа.
- **Три раздела**, переключаются кнопками:
  - **📊 Графики** — остаток долга, структура общей стоимости, структура
    платежа по месяцам.
  - **📋 График платежей** — таблица по месяцам, кнопка «Скачать таблицу в CSV»,
    раскрывающийся блок «Итоги по годам».
  - **⚖️ Сравнение** — таблица «аннуитет против дифференцированного», график
    платежей в начале и в конце срока, вывод об экономии на процентах.

Все графики интерактивные: наведение показывает точные суммы, легенда
отключает серии, есть масштабирование области.

## 4. Установка с чистого компьютера

Ниже полная последовательность для машины, на которой ничего нет, кроме
операционной системы. Команды для Windows PowerShell, для macOS и Linux —
в конце раздела.

### 4.1. Установить Python

Проверьте, есть ли уже подходящая версия:

```powershell
python --version
```

Если команда не найдена или версия ниже 3.11, скачайте установщик с
<https://www.python.org/downloads/> и при установке обязательно отметьте
галочку **Add python.exe to PATH**.

Проверка после установки:

```powershell
py --version
```

### 4.2. Проверить, что Git доступен

```powershell
git --version
```

Если Git нет, скачайте его с <https://git-scm.com/download/win> и перезапустите
терминал.

### 4.3. Получить код проекта

```powershell
cd $HOME\Documents
```

```powershell
git clone https://gitverse.ru/Yulya-com/dashboard-ipoteka.git mortgage-dashboard
```

```powershell
cd mortgage-dashboard
```

После клонирования единственный remote называется `origin` и ведёт на GitVerse.
Именно с него вы скачали код.

Тот же проект есть на GitHub. Чтобы держать обе площадки и отправлять код в
обе, добавьте второй remote с именем `github`:

```powershell
git remote add github https://github.com/Yulya-com/mortgage-dashboard.git
```

Проверьте, что получилось — должно быть две строки:

```powershell
git remote -v
```

```
github  https://github.com/Yulya-com/mortgage-dashboard.git (fetch)
github  https://github.com/Yulya-com/mortgage-dashboard.git (push)
origin  https://gitverse.ru/Yulya-com/dashboard-ipoteka.git (fetch)
origin  https://gitverse.ru/Yulya-com/dashboard-ipoteka.git (push)
```

Если вы клонировали с GitHub, а не с GitVerse, картина обратная: `origin`
ведёт на GitHub, а GitVerse добавляется так:

```powershell
git remote add gitverse https://gitverse.ru/Yulya-com/dashboard-ipoteka.git
```

Дальше в README используются имена из первого варианта: `origin` — GitVerse,
`github` — GitHub. Если у вас наоборот, поменяйте имена в командах местами.

Второй remote нужен только для синхронизации двух площадок. Для работы с
приложением достаточно одного.

### 4.4. Создать виртуальное окружение

Виртуальное окружение — отдельная папка с библиотеками проекта. Нужна, чтобы
зависимости приложения не смешивались с системным Python.

```powershell
python -m venv .venv
```

Появится папка `.venv`. Она не попадает в Git — это правильно, окружение
пересоздаётся одной командой.

### 4.5. Активировать окружение

```powershell
.\.venv\Scripts\Activate.ps1
```

Признак успеха — в начале строки приглашения появилось `(.venv)`:

```
(.venv) PS C:\Users\you\Documents\mortgage-dashboard>
```

Проверка, что активировался нужный Python:

```powershell
python -c "import sys; print(sys.executable)"
```

Путь должен вести внутрь `.venv`.

Если PowerShell выдал ошибку про отключённые сценарии, выполните один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Альтернатива без смены политики — не активировать окружение, а обращаться к
Python внутри него напрямую. Тогда все команды ниже записывайте как
`.\.venv\Scripts\python.exe -m ...` вместо `python -m ...`.

### 4.6. Установить зависимости

```powershell
python -m pip install --upgrade pip
```

```powershell
python -m pip install -r requirements.txt
```

Установятся три библиотеки: Streamlit, Plotly, pandas. Это занимает 1–3 минуты.

Проверка:

```powershell
python -m pip list
```

В списке должны быть `streamlit`, `plotly`, `pandas`.

## 5. Запуск

Из папки проекта, при активированном окружении:

```powershell
streamlit run app.py
```

Приложение откроется в браузере автоматически. Если этого не произошло,
откройте вручную:

```
http://localhost:8501
```

Остановить сервер — `Ctrl + C` в терминале.

Запуск без активации окружения, одной командой:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Запуск на другом порту, если 8501 занят:

```powershell
streamlit run app.py --server.port 8502
```

Доступ с телефона или другого компьютера в той же сети — используйте адрес,
который Streamlit печатает в строке `Network URL`, например
`http://192.168.0.31:8501`.

## 7. Проверка работоспособности

### 7.1. Автоматические тесты

Установите тестовые зависимости:

```powershell
python -m pip install -r requirements-dev.txt
```

Запустите тесты:

```powershell
python -m pytest
```

Ожидаемый результат:

```
36 passed
```

Если тесты падают, приложение запускать не стоит — сначала раздел
[13](#13-если-что-то-не-работает).

### 7.2. Проверка расчёта без интерфейса

Быстрая проверка формул из командной строки:

```powershell
python -c "from datetime import date; from calculator import MortgageParams, calculate; r = calculate(MortgageParams(12_000_000, 2_400_000, 12.5, 240, 'annuity', date(2026,10,1))); print(r.monthly_payment, r.total_interest, r.total_paid)"
```

Ожидаемый вывод:

```
109069.49 16576680.29 26176680.29
```

### 7.3. Проверка сервера

Запустите приложение и во втором терминале проверьте, что сервер отвечает:

```powershell
curl.exe -s http://localhost:8501/_stcore/health
```

Ответ должен быть `ok`.

### 7.4. Проверка основного сценария вручную

1. Откройте `http://localhost:8501`.
2. Оставьте значения по умолчанию: 12 000 000 ₽, взнос 2 400 000 ₽, ставка
   12,5 %, срок 20 лет, аннуитетный платёж.
3. Сверьте карточки: платёж **109 069,49 ₽**, сумма кредита **9 600 000 ₽**,
   переплата **16 576 680 ₽**, всего выплат **26 176 680 ₽**.
4. Переключите тип платежа на дифференцированный: первый платёж должен стать
   **140 000,00 ₽**, переплата уменьшиться до **12 050 000 ₽**.
5. Откройте раздел «📋 График платежей»: в таблице 240 строк, в последней
   строке остаток долга равен нулю.
6. Нажмите «Скачать таблицу в CSV» и откройте файл в Excel: колонки на русском,
   числа с запятой, даты в формате `01.10.2026`.
7. Переключите тему на тёмную: фон, карточки и графики должны потемнеть.
8. Введите взнос, равный стоимости: должно появиться сообщение
   «Первоначальный взнос должен быть меньше стоимости недвижимости», вместо
   карточек — текст ошибки.

Все восемь пунктов выполняются без перезагрузки страницы.

## 8. Переменные окружения

**Приложение не использует переменные окружения.** Значения не нужны, файл
`.env` создавать не требуется. Секретов в коде нет.

Для справки — имена переменных, которые понимает сам Streamlit, если их
задать. Все необязательны, значения по умолчанию берутся из
`.streamlit/config.toml`:

| Имя | Назначение |
|---|---|
| `STREAMLIT_SERVER_PORT` | порт сервера |
| `STREAMLIT_SERVER_ADDRESS` | адрес, на котором слушать |
| `STREAMLIT_SERVER_HEADLESS` | не открывать браузер автоматически |
| `STREAMLIT_BROWSER_GATHER_USAGE_STATS` | телеметрия использования |
| `STREAMLIT_THEME_BASE` | базовая тема оформления |

Приложение не читает эти имена в коде, их влияние ограничено настройками
сервера Streamlit.

Файлы, которые исключены из Git и могут содержать секреты:

```
.env
.streamlit/secrets.toml
```

Оба шаблона уже прописаны в `.gitignore`. Если добавите свои ключи, храните их
только в этих файлах и никогда не коммитьте.

## 9. Деплой

### 9.1. Streamlit Community Cloud (бесплатно, из GitHub)

Подходит, если нужна публичная ссылка без своего сервера.

1. Убедитесь, что код есть в GitHub-репозитории `Yulya-com/mortgage-dashboard`
   и `app.py` лежит в корне (так и есть).
2. Откройте <https://share.streamlit.io> и войдите через GitHub.
3. Нажмите **New app** и укажите: репозиторий `Yulya-com/mortgage-dashboard`,
   ветку `main`, файл `app.py`.
4. Нажмите **Deploy**. Сборка занимает 2–5 минут, зависимости ставятся из
   `requirements.txt`.

Результат — адрес вида `https://<имя>.streamlit.app`, доступный с любого
устройства. Каждый `git push` в ветку `main` репозитория на GitHub автоматически
перезапускает приложение. Отправка только на GitVerse обновление не запускает —
именно поэтому в разделе 11.1 код пушится на обе площадки.

Ограничение платформы: приложение засыпает после периода без посещений и
просыпается при первом открытии.


Запуск с доступом извне:

```bash
.venv/bin/streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

Чтобы приложение работало постоянно, оберните команду в systemd-сервис или
`screen`/`tmux`, а перед ним поставьте reverse proxy (nginx, Caddy) с HTTPS.

### 9.3. GitVerse

GitVerse используется как вторая площадка для кода. Публикация самого
Streamlit-приложения там не предусмотрена: Pages отдаёт статические файлы, а
приложению нужен работающий Python-процесс. Рабочие варианты — держать код на
GitVerse, а запускать на Streamlit Cloud (пункт 9.1) или своём сервере
(пункт 9.2), либо использовать GitVerse CI/CD для сборки и доставки на сервер.

## 10. Обновление

Перейти в папку проекта:

```powershell
cd $HOME\Documents\mortgage-dashboard
```

Забрать свежий код с GitVerse (это `origin` после клона по разделу 4.3):

```powershell
git pull origin main
```

Или с GitHub:

```powershell
git pull github main
```

Обновить зависимости, если менялся `requirements.txt`:

```powershell
python -m pip install -r requirements.txt
```

Перезапустить приложение: `Ctrl + C` в терминале, затем снова

```powershell
streamlit run app.py
```

Перезапуск обязателен. Streamlit кэширует импортированные модули, и правки в
`calculator.py`, `charts.py`, `theme.py` не подхватятся без него.

Посмотреть, что изменилось с вашей последней версии:

```powershell
git log --oneline -10
```

Откатиться к предыдущей версии, если обновление что-то сломало:

```powershell
git revert HEAD
```

## 11. Резервное копирование

### 11.1. Код

Код хранится в трёх местах: локальная папка, GitHub, GitVerse. Потеря одного
из них не критична.

Синхронизировать локальную копию с обеими площадками:

```powershell
git push origin main
```

```powershell
git push github main
```

Проверить, что всё отправлено (обе команды должны вернуть `0 0`):

```powershell
git rev-list --left-right --count main...origin/main
```

```powershell
git rev-list --left-right --count main...github/main
```

Если вторая команда падает с ошибкой `unknown revision`, значит площадка ещё не
подключена или вы ни разу на неё не отправляли. Вернитесь к разделу
[4.3](#43-получить-код-проекта) и добавьте второй remote.

### 11.2. Автономная копия одним файлом

`git bundle` упаковывает весь репозиторий с историей в один файл. Удобно
положить на флешку или в облако.

```powershell
git bundle create mortgage-dashboard-backup.bundle --all
```

Восстановление из такого файла на другой машине:

```powershell
git clone mortgage-dashboard-backup.bundle mortgage-dashboard
```

### 11.3. Простая копия папки

Если Git недоступен, достаточно скопировать папку проекта целиком. Папку
`.venv` можно не копировать — она пересоздаётся командой
`python -m venv .venv`.

### 11.4. Что резервировать не нужно

- `.venv/` — пересоздаётся из `requirements.txt`.
- `__pycache__/`, `.pytest_cache/` — временные файлы.
- Выгруженные CSV — это результат расчёта, его всегда можно получить заново.

Пользовательских данных приложение не хранит, отдельная резервная копия базы
не требуется.

## 12. Известные ограничения

**Расчётная часть**

- Только месячные платежи, без промежуточных взносов и досрочных погашений.
- Не учитываются страховка, налоги, комиссии банка, материнский капитал и
  субсидии — только тело кредита и проценты.
- Одна валюта, символ `₽` зашит в форматирование.
- Ставка постоянная на весь срок, без плавающих и ступенчатых ставок.
- Срок ограничен 600 месяцами (50 лет), ставка — 100 %.
- Последний платёж корректируется на копейки, чтобы остаток закрылся ровно в
  ноль. Поэтому он может отличаться от остальных на 1–3 рубля.

**Интерфейс**

- Переключатель темы находится в нижней части сайдбара под кнопкой сброса, а не
  наверху — виден только после прокрутки.
- Контраст двух цветов светлой темы ниже требований WCAG AA: янтарный
  `#F59E0B` на фоне даёт 1.99:1, зелёный `#0E9F6E` — 3.13:1. Текст и подписи
  осей читаются нормально, но серии графиков этих цветов различимы хуже.
- Интерфейс только на русском языке.
- Нет сохранения сценариев: при перезагрузке страницы параметры сбрасываются.

**Эксплуатация**

- Нет базы данных и авторизации: приложение не различает пользователей.
- Нет встроенного Docker-файла, деплой описан для Streamlit Cloud и systemd.
- В репозитории нет скриншота интерфейса, только схема в разделе 2.
- Приложение рассчитано на один процесс; для нагрузки нужен внешний
  балансировщик.

## 13. Если что-то не работает

### `python` не найден или «не является внутренней командой»

Python не в PATH. Проверьте альтернативный запуск:

```powershell
py --version
```

Если работает `py`, используйте его вместо `python`: `py -m venv .venv`. Если не
работает ни то, ни другое — переустановите Python с галочкой **Add python.exe
to PATH**.

### `Activate.ps1` не запускается: «выполнение сценариев отключено в этой системе»

Политика PowerShell запрещает локальные скрипты. Разрешить для текущего
пользователя (без прав администратора):

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Разрешить только на время текущего терминала:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Либо не активировать окружение вообще:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

### `ModuleNotFoundError: No module named 'streamlit'`

Команда выполняется не в том Python. Признак — в приглашении нет `(.venv)`.
Активируйте окружение и проверьте путь:

```powershell
python -c "import sys; print(sys.executable)"
```

Путь должен содержать `.venv`. Если нет — выполните
`.\.venv\Scripts\Activate.ps1` и повторите установку.

### Порт 8501 уже занят

Узнать, кто держит порт:

```powershell
Get-NetTCPConnection -LocalPort 8501 -State Listen | Select-Object OwningProcess
```

Закрыть процесс по найденному номеру (подставьте свой):

```powershell
Stop-Process -Id 12345 -Force
```

Или просто запустить на другом порту:

```powershell
streamlit run app.py --server.port 8502
```

### Приложение открылось, но показывает старый код

Streamlit держит модули в памяти. Остановите сервер (`Ctrl + C`) и запустите
заново. Для автоматической перезагрузки при сохранении файлов:

```powershell
streamlit run app.py --server.runOnSave true
```

### `StreamlitDuplicateElementId`

В коде появились два элемента с одинаковыми параметрами — обычно два
`st.plotly_chart` с одинаковой фигурой на одной странице. Один из них нужно
развести через параметр `key`:

```python
st.plotly_chart(fig, key="chart_balance")
```

### В терминале кракозябры вместо русского текста

Консоль Windows не в UTF-8. Включить для текущего окна:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

На содержимое файлов и работу приложения это не влияет — только на вывод в
терминале.

### CSV в Excel открывается одной колонкой

Файл выгружается с разделителем `;` и BOM UTF-8, поэтому в русской локали Excel
открывает его правильно. Если разделитель всё же не распознан, используйте
**Данные → Из текста/CSV** и укажите разделитель `;` вручную.

### `pip install` падает с ошибкой SSL или таймаутом

Проверьте соединение и повторите с увеличенным таймаутом:

```powershell
python -m pip install -r requirements.txt --timeout 120
```

За корпоративным прокси может понадобиться указать его адрес:

```powershell
python -m pip install -r requirements.txt --proxy http://proxy.example:8080
```

### `git clone` просит пароль, а пароль не подходит

GitVerse и GitHub не принимают пароль аккаунта для Git-операций. Нужен токен
доступа:

- GitVerse: Настройки → Управление токенами → отметить «Репозитории» →
  сгенерировать.
- GitHub: Settings → Developer settings → Personal access tokens.

В окне входа укажите логин и токен вместо пароля.

### `git push` на GitVerse открывает страницу 404 `/login/oauth/authorize`

Git Credential Manager пытается применить OAuth-схему, которой у GitVerse нет.
Отключите его для этой операции:

```powershell
git -c credential.helper= push origin main
```

Здесь `origin` — имя GitVerse в вашем репозитории. Если GitVerse подключён под
именем `gitverse`, подставьте его. Токен в этом случае Git спросит в окне
ввода: логин `Yulya-com`, пароль — токен.

## 14. Формулы расчёта

**Аннуитетный платёж** — одинаковый весь срок:

```
P = S · i / (1 − (1 + i)^(−n))
```

где `S` — сумма кредита (стоимость минус взнос), `i` — месячная ставка
(`годовая / 100 / 12`), `n` — срок в месяцах.

Последний платёж корректируется, чтобы остаток долга закрылся ровно в ноль.

**Дифференцированный платёж** — убывающий. Основной долг делится на `n` равных
частей, проценты начисляются на текущий остаток:

```
P_k = S / n + S_ost(k−1) · i
```

где `S_ost(k−1)` — остаток долга перед платежом `k`.

**Переплата** — сумма всех процентов за срок. **Доля переплаты** — переплата,
делённая на сумму кредита.

При ставке 0 % обе схемы дают одинаковый результат: кредит делится на срок без
процентов.
