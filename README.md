# Ипотечный калькулятор с дашбордом

Веб-приложение на Streamlit: считает ипотеку по аннуитетной или
дифференцированной схеме, показывает итоговые показатели, график платежей,
интерактивные графики Plotly и выгружает таблицу в CSV.

## Возможности

- **Параметры**: стоимость недвижимости, первоначальный взнос, годовая ставка,
  срок в годах, тип платежа, дата первого платежа.
- **Показатели**: ежемесячный (или первый) платёж, сумма кредита и доля взноса,
  переплата по процентам, общая сумма выплат.
- **Разделы**: «Графики», «График платежей», «Сравнение» — переключаются
  сегментированным контролом, активный раздел пересчитывается заново.
- **Графики**: остаток долга, структура каждого платежа, доля переплаты,
  сравнение аннуитета и дифференцированного платежа. Подписи осей в рублях
  (`млн ₽` / `тыс ₽`) с запятой как десятичным разделителем.
- **Таблица**: полный график платежей с датами, процентами, основным долгом и
  остатком; итоги по годам; экспорт в CSV (Excel-совместимый: `;`, запятая в
  дробях, BOM UTF-8).
- **Темы**: светлая и тёмная, переключаются в сайдбаре и применяются к
  интерфейсу, карточкам, полям ввода и графикам.
- **Валидация**: пустые, нулевые, отрицательные и нечисловые значения,
  взнос больше или равен стоимости, ставка вне 0–100%, срок вне 1–600 месяцев.
  Ошибки показываются списком, а не первой попавшейся.
- **Сброс**: кнопка возвращает параметры по умолчанию, не зацикливая rerun.

Расчётный модуль не импортирует Streamlit, а модуль графиков не зависит от
интерфейса — логику можно переиспользовать и тестировать отдельно.

## Установка и запуск

```powershell
cd mortgage-dashboard
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на <http://localhost:8501>.

## Тесты

```powershell
pip install -r requirements-dev.txt
pytest
```

36 тестов: формулы и границы расчёта, валидация, форматирование, CSV,
построение фигур Plotly и темы.

## Формулы

Аннуитетный платёж:

```
P = S · i / (1 − (1 + i)^(−n))
```

где `S` — сумма кредита, `i` — месячная ставка (`годовая / 100 / 12`),
`n` — срок в месяцах. Последний платёж корректируется, чтобы остаток долга
закрылся ровно в ноль.

Дифференцированный платёж: основной долг делится на `n` равных частей,
проценты начисляются на текущий остаток, поэтому платёж убывает.

## Безопасность

Секретов в коде нет: приложение не обращается к внешним API, не хранит
персональные данные и работает полностью локально. Файлы
`.streamlit/secrets.toml` и `.env` исключены через `.gitignore`.
